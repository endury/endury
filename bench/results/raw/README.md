# Raw answers

These are unedited answers from AI language models, kept as evidence for the
benchmark in [bench/](../../README.md). Each folder names the AI model and its
maker. The answers in the `x-ai` folders were written with Grok.

They are AI-generated and were graded, not reviewed as plans, and some are
unsound. They are not training advice. The AGPL that covers Endury's own code
claims no rights in them.
