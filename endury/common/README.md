# endury/common

Cross-cutting helpers with no domain of their own.

| Module | What it does |
| --- | --- |
| `clock.py` | The injectable clock every time read goes through, and `daypart()`. |
| `exceptions.py` | `EnduryError` and `RepositoryError`. |
| `memory_notes.py` | The athlete-memory document's conventions: headings, due check-ins, the review dates of constraints. |

Start reading: [clock.py](clock.py).
